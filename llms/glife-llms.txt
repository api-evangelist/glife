# Glife Technologies

> Glife is a Singapore-based food-tech company growing a better food future across Southeast Asia. It operates a farm-to-business/consumer commerce and supply-chain platform connecting farmers, suppliers, restaurants, and retail customers, backed by a GraphQL application API.

## API

- [Glife GraphQL API](https://api-sg.glifeware.com/graphql): GraphQL endpoint backing the Glife commerce + supply-chain platform (535 queries, 870 mutations, 139 subscriptions).

## Specs

- [GraphQL SDL](graphql/glife-schema.graphql): Full introspected schema.
- [GraphQL introspection](graphql/glife-graphql-introspection.json): Raw introspection response.
- [Authentication](authentication/glife-authentication.yml): Token-based auth via login mutations.
- [Conventions](conventions/glife-conventions.yml): Pagination, filtering, subscriptions.
- [Data model](data-model/glife-data-model.yml): Core entity-relationship graph.
